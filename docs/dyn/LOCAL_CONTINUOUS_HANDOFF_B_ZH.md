# Local B：有界移动接续的实现边界

状态：设计契约，尚未接入执行。本次仅实现 Explorer 的未来站位重验和决策证据，Local、Controller、ROS 消息及速度/安全阈值未变。本文约束后续 B 的实施，不代表当前已支持未来接续区间。

## 要解决的现场问题与第一版范围

Campus record-3 的需求218在689.04/720.05 s均已由Explorer发布。候选计算完成后，Local接入误差0.673/0.582 m，大于对应动态限值0.10 m，于是HOLD并转入出发失败。这不是Controller的0.02 m证书变化检查拒绝：该记录中未出现HANDOFF_CERTIFICATE_STATE_CHANGED或HANDOFF_CERTIFICATE_HEADING_CHANGED。不能放大安装容差来掩盖生成起点已经落后的问题。

第一版只接管正常前进时，同一任务滚动及无需初始原地转向的任务successor。独立信息满足可以立刻记账和准备后续任务，但并不立即转移运动所有权。已在HEADING_FROZEN、终点捕获、固定朝向恢复、前进转向预备或安全HOLD的执行，不使用普通移动接续证书；分别等待该动作完成或明确终止，再生成合适的接续。不能将当前Local的HANDOFF_ROLLING_ALIGNMENT_PENDING改成无条件允许安装。

## 规划源必须是同一份真实执行快照

快照至少含前任request/trajectory/task/version、执行模式、已安装位置/速度/加速度曲线、最近Controller反馈的实测进度、世界系速度、身体yaw/yaw rate、位姿/反馈时间戳和时效、地图证据版本与地形参考。当前FSM使用executionProgressTime，而planner_manager内部suffix仍自行用now-start_time；实施B时先消除这两层的切割点分歧。

不能靠一个最接近的XY点认定执行进度：自交、回头、近静止或掉头处可能有多个近点。进度匹配需绑定前任版本及有限的向前范围，结合姿态、运动方向与反馈新鲜度。冻结和暂停期间不按墙钟向前外推。规划超时使用steady clock，几何进度使用Controller/odom；仿真与墙钟转换不得假定RTF恒为1。

## 接续区间怎样确定

在仍通过必要安全检查的T1前方选择有限进度区间[u0,u1]。u0必须留下可完成候选计算、认证、传输与提交的提前量；u1必须早于T1失去安全执行/制动退路的最后进度，同时不能越过观测停车端点或尚未完成的特殊动作。没有满足条件的区间就返回NO_SAFE_CONNECTION_WINDOW；计算来不及返回DEFERRED_CAPACITY或EXPIRED，不能据此宣布站位/区域不可达。

提前量来自实测延迟分布及有界余量，并用当前执行进度和可达速度界转换为进度范围，不固定写成2–3 m或1.5 s。不能拿P99本身当硬实时保证；有限提交截止和可靠制动退路仍必须独立存在。

T2以该区间内的前任未来状态为起始边界生成。证书是按接续进度关联的状态管道或少量逐点认证的接续槽，而不是任意位置、速度、yaw区间的笛卡尔积。只对已验证组合有效，禁止Controller自由选择一个未经认证的matched_time。第一版可先用很少的离散槽，每槽明确前任进度、T2进度与可接受状态误差，避免实现完整连续可达集。

## 证书认证什么

几何上覆盖连接区、机体转弯扫掠及独立制动退路；地图依据包含原始占据/UNKNOWN、地面支撑与Z参考、净空及相关证据版本。运动上检查位置、世界系速度、加速度与实际身体yaw/yaw rate接续；T2切线相近不等于身体已能执行。路径曲率、命令限幅、步态响应和地形相关制动能力使用统一的平台能力版本。

至少需要显式验证位置/速度连续性，并按既有B-spline与跟踪器要求约束加速度及偏航过渡。不能只凭C2曲线宣布步态动态安全，也不能让Local和Controller分别使用不一致的制动模型生成两套连接界。数值误差范围必须由已覆盖的扫掠/跟踪/制动裕量推出，保留Controller对恶意或越界证书的上限检查；当前0.02m/0.02rad不因本设计自动放宽。

证书绑定前任版本、后继候选版本、任务/信息意图版本、能力版本、实测反馈序号、相关地图证据、有效进度槽与steady截止。只要前任被替换、任务被取消、反馈过期、进度错过槽、特殊动作owner变化或安全前缀失效，证书就失效。远处无关地图更新不应自动使它过期，但这需要先实现可证明的局部证据依赖；实现前宁可重新认证，不能假定地图没影响。

## 安装与执行所有权

Controller始终是唯一安装权威。Local只提交不可变候选与证书，不能修改正在执行的T1控制点。最多一个移动接续处于待安装；待安装候选不会覆盖当前执行快照。

Local PREPARE → VALIDATED/ARMED只表示候选已认证。Controller接收后先检查前任和证书，并报告STAGED，不报告INSTALLED；T1继续执行。进入已认证槽且实时状态满足对应约束时，原子切换到T2，再发布准确的INSTALLED ACK，Local和Explorer才据此提交。第一版可沿用现有单候选权威扩展必要状态，禁止Local和Controller各自选择不同切换时刻。

准备、到达接续槽和实际安装是不同截止。STAGED不能续命一个已过期的槽；任何阶段都不得无限等待。取消B只取消B，不能误退役仍在执行的A。若ACK途中真实已经安装，则以准确执行版本反馈对账，不能因为本地超时重发另一份并假定A还在执行。

若未赶上槽，保留仍安全、仍有制动余量的T1，并有界准备下一次；不满足继续执行条件时由现有安全权威减速/HOLD。候选失败、计算等待、连接错过、旧前缀失效和物理受阻分别反馈。一次普通未安装候选失败不能直接耗尽脱困预算或成为Explorer方向失败证据。

## 与A及Explorer的关系

B先定义可信连接点和所有权，A再固定T1可保留部分，仅优化受影响连接区和尾部。B-spline控制点与结点变化的影响范围需要显式计算；修改尾部或重定时不能悄悄改动固定执行前缀。第一版仍可安装一份完整的新轨迹版本，不要求立即引入Controller分段轨迹队列。

Explorer选择需求和可重验站位，允许移动中观测满足；Local决定何时、怎样安全切换运动。不延迟信息完成来保护转向，也不把每次信息更新变成必须即时抢占运动的新合同。

## 实施顺序与验收

1. 统一FSM、Manager、Controller使用的执行版本与实测进度，回归转向冻结、低速滞后、自交路线、迟到反馈；先不改安全阈值。
2. 在现有候选/ACK链中加入很少的接续槽与STAGED/INSTALLED区分，生成、连接、认证、Controller安装、Local快照提交一起改；普通同任务滚动先通过，再接任务successor。
3. 验证取消未安装B不影响A、错过槽仍有安全前缀、前任替换拒绝旧证书、地图相关变化失效、无关变化不制造churn、观测在转向中提前满足不抢占owner。
4. 用218两次失败作为反例，另用当前正常连续滚动的成功短后缀作为对照，记录起点预测误差、生成/认证耗时、槽命中与错过原因、准确ACK延迟、每米非必要停车、制动退路覆盖。安全绕过数必须为零；不得靠统一增大容差制造“安装率改善”。

这一步不以“永不停车”为目标。只有证据支持时连续接续，真实风险和任务停车要求仍有明确停止出口。

# Explorer 连接计算持续推进：2026-11-01

本轮替换等待时的计算入口，仍由Explorer拥有信息满足，Local拥有运动认证，Controller拥有安装。Global与Local执行代码未修改。不是全局Region增量划分的完整实现。

## 替换的旧路径

prepare_next_observation与plan_from_current_position在重新提取Frontier、划分Region和枚举站位之前，先检查是否存在同一份待完成连接。连接未完成时保存当前至多3个Region的候选事实，不保留整张地图快照。后续回调按同一目标域重验站位、观测收益及raw FREE连接，并推进路线计算。信息满足交接和观测不足换站不再在同一等待后落回另一轮完整规划。地图不变不再阻止合法续算。

一次新的决策仍会走现有Region构建；只有当前连接等待期间退出重复Region/候选构建。该修改没有解决所有冷启动Region划分的成对A*成本。

连接拥有最多一个未完成A*工作集。当前终端连接可以使用本轮剩余的共享4096预算，其他候选可复用已完成路径或直连见证，否则明确等待同一计算槽；不会创建另一份搜索挤掉它。实际问题改变后显式释放旧owner。原搜索的相关格/边变化仍使其重新计算，距离超过1m的新起点或任务/作用域/排除/约束/运动epoch/地图几何改变会退出原候选批次。此1m沿用现有粗路线接入尺度，不是机体安全或误差许可。

未来区域的非直连转移仅给明确的距离估计，不再创建与当前连接竞争的未完成A*。已完成路线和直连仍复用；preview_estimated保留。未来目标真正提升为当前发布候选时仍需raw FREE路线见证。搜索容量超过原20,000展开上限时仍明确SEARCH_CACHE_CAPACITY，不伪装为物理不可达，也不扩大预算。

已安装前缀仍存活的需求可从计划引用重新挂入采样池：释放加速缓存不再使同一承诺目标域自动新建ID。实际观测满足和原任务测量基线不改变。

## 验收

355项既有/新增回归后另补入口集成，最终357项通过。新增测试覆盖静态输入推进、无关地图更新保留工作、真实约束改变使其退出、观测提前满足不发布旧站位、起点超出接入范围、同一回调不执行第二套fallback、准备入口不重新调用Frontier/Region构建、前瞻Region提升后连接能够持续推进，以及安装需求从计划重新挂接。

从record-4重建1137s冻结占据，使用最终实际任务的站位与目标代表，调用真实resume_visit_connection：3次调用分别展开4096、4096、2915，找到连接，总计算约220–272ms；期间Region重划分0次、站位枚举0次。没有额外有向禁用边，观测域用消息代表格，未逐帧重放全部现场调度、地图变化、完整隐藏目标域和Local执行，所以不是将实际85.8秒停顿直接缩短为该计算时间的闭环证据。

同一冻结地图，实际目标周围8个FREE端点的40轮缓存压力复现：原来320次均SEARCH_INCOMPLETE、61次搜索重建；修改后226次获得已知自由连接，94次仍在等待/计算，搜索对象重建为0，保留工作集没有被其他候选淘汰。总预算和内存上限不增加。

日志REGION_CONNECTION_RESUME区分续算耗时、展开和结果；visit_stats.connection_owner记录起点、目标与已展开格数。续算时Region划分/地图预处理计时清零，避免把之前一次全量工作的耗时误记为续算成本。现有REGION_VISIT_DECISION、计划发布/安装日志继续使用。

## 剩余边界

新Region决策仍需现有全图划分，不承诺其251ms成本已经消除。连续新任务改变上下文、相关地图反复变化或所有连接均超过容量时，仍可能等待，必须根据实际退出原因判断；本轮不增加超时或不可达黑名单。Local B接续协议与普通滚动的停车问题不在本轮修改范围。安装入口链接源码，新的Explorer进程加载本次修改。

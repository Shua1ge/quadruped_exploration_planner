# 无 Vision 阶段的 Global：空间记忆与计算替代设计

状态：设计约束与分阶段验收，尚未实现本页全部内容。2026-10-30 已实现空间身份与凸支撑分离、净空来源和格误差、度二连接压缩及支撑接入，见 [实现语义](GLOBAL_GEOMETRY_SEMANTICS_ZH.md)；全链路增量发布、路线服务替代仍按下文阶段验收。当前 Global 继续 shadow，不接入 Explorer 选路、任务选择或 Local 运动合同；共享 CPU 开销单独计量。第一阶段只使用 LiDAR、采集位姿、LocalMapPatch、已有地形摘要及实际执行反馈；不启用 Vision、不加入预测可通行地图、不改 Local 安全门限。

## 1. 目标与唯一职责

Global 要逐步替代 Explorer 对历史已知空间的重复路线计算，并保存稳定的连接身份。它的价值由有效候选接入、真实替代路线、计算总成本和尾延迟证明。地面分区、图维护和路线服务属于同一条链：可靠证据形成稳定空间与连接，连接提供批量查询，查询减少 Explorer 的计算。

Local 是测量解释、能力评估和本次可执行运动的权威。Global 累积已有证据支持的粗连接和代价，不重新从 Z/IMU 判断通行能力；Explorer 持有 Frontier、收益、剩余需求与探索承诺；Controller 安装并执行 Local 认证的运动。Global 的“已知空间有路线”不等于 Go2 可以按这条折线直接跟踪。

一个广场可以有一个空间身份、多个路由支撑域、若干探索工作集。Global 拥有前两者；Explorer 拥有最后一个。当前 Goal、Frontier 排名或机器人身体起伏不能直接重划 Global 空间。Global 的普通细化也不能自动终止 Explorer 的工作集或运动合同。

## 2. 复用已有数据，不建立另一张地图

继续以 Local 发布的未膨胀 occupancy、已测表面、自由证据和 TerrainTileSummary 为输入。复用 wavefront 的世界锚定 tile、FREE 分量、路径见证，SpatialDomainView 的派生支撑、现有 SparseRouteGraph 的候选接入和 batch_estimates_with_reasons，以及 TerrainTileStore。

Global 不新增 raw cloud 融合。IMU 先帮助 Local 对齐和评估；Global 不根据 IMU pitch/roll 的瞬时变化直接建点。Local 的坡度/净空/风险事实变化可使边代价过期，但不会被 Global 二次阈值化成墙。滑窗 UNKNOWN 不擦除长期历史；新旧事实按采集时间、map epoch 和来源版本处理。

第一轮保留现有消息接口，先把内部更新和 JSON 支撑语义收敛。确有不可表达的缺口时才扩展消息；不要为每种变化新增一套状态机或一张全局稠密图。

## 3. 空间身份、内部域与 Node 分开

内部凸支撑域可以因柱子、凹边或计算范围分成多块。这些分块服务于已知 FREE 路线构造，并非地面空间身份。此前 _merge_places 用整个并集凸包必须为 FREE 的条件合并身份，导致同一最终地图依观测顺序得到 6 或 1 个 place；2026-10-30 已将该条件保留在支撑域几何计算中，并从空间身份必要判据中移除。

空间身份按相邻支撑之间的实际接口和分隔证据维护。接口由共享边界上的已知 FREE 连通带及其邻域支撑构成，不能把一条粗 Edge 当成宽阔开口的证明。宽阔、持续有证据的相邻部分可以共享非凸空间身份，内部保留障碍孔；真实墙体、可验证窄口或结构分支可成为分隔依据。不能将整个 FREE 连通分量简单视为一个空间，也不能把 UNKNOWN 当作已确认的围墙。

窄口判断使用几何相对收缩、邻域宽度与已测边界证据，不使用“Go2 身宽能否通过”作为全局硬否决。证据不足时记录暂定接口，保持路线事实，避免新分组身份反复提交；后续证据确认后才提交分隔或合并事件。具体几何阈值在广场有柱、L 形空地、门连房间和窄廊回放上确定，不先凭截图固定单一阈值。

空间合并保留一个规范 ID，旧 ID 作为别名；真实分裂时主要保留部分继承原 ID。别名仅维护被外部引用和必要谱系，不无限保留每次计算分块。最终相同的稳定几何应得到等价空间分区，不要求不同扫描顺序下数值 ID 一样。正常观测扩展不能因尚未合完而永久留下碎片。

公开 Node 只在真实分支/接口、重要接入位置或已有支撑无法低成本服务远端接入时保留。多个内部域可以共用一个空间身份，Node 与颜色不是一一对应关系。开阔场地没有岔路时仍要保证覆盖和接入；不能为减少 Node 数量让大部分 Viewpoint 落到固定接入半径之外。代价变化通常更新 Edge，不必创建 Node；真实连接变化或必须显式表达的路线选择才调整结构。

## 4. Edge 表达哪些事实

Edge 至少保存其两端连接身份、已知 FREE 路线折线、长度、所依赖的 tile/来源版本和粗几何属性。地形属性来自 Local 的风险、速度比例、置信度、能力/策略版本，按路线覆盖范围聚合，不能只取一个锚点附近的值。方向相关的经验分别保存；短暂安装失败不写成永久方向封锁。

边的几何版本、代价版本与整体地图 revision 区分。局部代价改变只使依赖该边的估价失效；未影响连接和代价的 patch 不应清空全部路线缓存。路线备选经过障碍两侧或不同入口时，保留不同连接身份；不能因为端点相同就覆盖成一条边。优先检查和复用现有 portal/branch/edge 标识，确有并行连接表示缺口再做小范围扩展。

正常删除边需要对应几何或证据生命周期依据。预算不足、候选未计算、worker 忙、一次 Local 拒绝均不足以删除已知连接。真实碰撞、执行失败等反馈保留其范围、工况和撤销条件，由 Local/Explorer 按既有职责处理。

## 5. 变化如何贯穿增量维护

按现有 dirty tile 及依赖索引组织更新，复用 edge_dependencies，不新建通用空间数据库。一次普通 patch 的路径是：内容/证据变化分类 → 相关 tile 与接口 → 受影响支撑与边 → 相关代价与查询缓存 → 局部显示更新。无变化输入只更新时间信息，不制造结构 revision。

去掉普通更新中的全图 floor 集合复制、全部 place 重算、全部边地形刷新和完整绘制几何重建。建立队列或索引时先确认现有机制能否复用，避免从“全图扫描”变成维护两套完整依赖图。连接大分裂可能影响大片子图，需分预算处理并原子提交一致版本；未完成重建可以返回等待，不能同时发布新 Node 和仍指向旧 Node 的 Edge。

Marker 按空间/更新块使用稳定 namespace/id，只删除失效块；普通刷新不重新发送全部地面三角形。低频完整快照用于新订阅者与恢复，和高频增量分开计时。颜色只表达空间身份；内部域、证据年龄和代价是可单独打开的诊断。固定 XY 平面标注为投影，不用机身 Z 假造历史地面高程。

## 6. 将来替代 Explorer 的哪部分

先替代从当前位置到多个候选的历史已知路线估价，再替代候选之间的粗路线估价与重复接入搜索。Explorer 仍提出候选并计算真实信息收益；Global 通过现有批量接口回答位置/候选怎样接入、已知路线代价与路径见证、相关版本及无法回答的原因。

已有 Edge 折线接入、空间支撑接入和共享搜索树应统一走一套查询判据。已知路线有效、已知空间当前不连通、证据不足/未挂接、预算等待和过期应可区分；这些是现有返回原因的明确语义，不额外增加运动 FSM。后四者不能被统一解释成“目标不可达”，更不能自动删除 Frontier。Explorer 可以对少量候选使用有界细查回退，回退次数、展开量与时间单独统计。

Global route_cost 尚未启用时，在离线回放或旁路比较相同候选，不在 shadow 模式暗中改变 Explorer 排名。保持结构细化前后的接入稳定：Edge 拆分只更新引用和估价，不代表探索分支、Region 或观测任务已经改变。

本阶段暂不改变 Explorer 的开阔工作集承诺、两步信息前瞻、目标切换权重或 Local 滚动。未来修这些内容时使用稳定空间引用，仍由 Explorer 唯一管理信息工作集。Global 优化是否 Efficient，不能靠同时改 Explorer 策略后覆盖率变好来证明。

## 7. 无 Vision 时如何保留通行机会

Global 保留有测量支持的几何接入与替代路线，消费 Local 的软代价和置信度；不因自己的二维表示、体态变化、接入预算或能力信息缺失，再增加一层硬不可达。这可以减少被错误全局表示提前排除的候选，具体机会仍由 Local 的几何、地形与当前步态认证决定。

这不等于无条件允许更陡坡或放松净空。没有能力证据时保持未知，不编造可执行性。以后 Vision/RL 提供新能力或成功经验，只更新带 capability/policy 版本的属性，不需要重新定义空间图；本阶段不接视觉网络，不训练新模型，不预支尚未验证的能力收益。

## 8. 实施与验收顺序

1. 修空间身份与显示。对相同最终地图、不同扫描顺序，要求稳定后的分区等价；广场带柱、L 形空地可共享非凸空间；真实门/窄口保留分隔依据；所有障碍和 UNKNOWN 孔保持原样。内部多个路由域允许继续存在。保持 shadow，实际运动输入不变。
2. 将 dirty 依赖贯穿维护和发布。以相同局部变化叠加不断增长的历史地图，分别计时融合/结构更新/压缩/地形/查询/序列化/显示，普通更新主要随受影响子图增长；大连通变化单独统计。检查快照、增量乱序和 map epoch，禁止混合版本。
3. 完成候选接入与批量查询旁路。固定同一组候选，比较稀疏估价和已有稠密参考的接入、路径代价及连通性，保留必要替代路线。统计未挂接、预算等待、过期、真实已知不连通与细查回退，不能以降低候选数量制造高命中率。
4. 达标后才申请单独启用 route_cost。以 Global off、旧实现、新实现使用相同输入，比较 Global＋Explorer 总 CPU、p95/p99 连续耗时、稠密展开量、候选接入和覆盖/路径效率。单 A76 的目标需在对应设备或受控等效预算下验证；不承诺固定倍数提速。Local 认证和执行语义不变，失败时可回到 shadow/off。

先前只读审计已确认严格凸合并与历史依赖问题；本轮修复及回归范围以实现语义页为准，性能发布改造和 Explorer 查询替代尚未完成。历史观察模式说明见 [GLOBAL_OBSERVATION_ZH.md](GLOBAL_OBSERVATION_ZH.md)，它记录的是现有实现，不是本页验收结果。

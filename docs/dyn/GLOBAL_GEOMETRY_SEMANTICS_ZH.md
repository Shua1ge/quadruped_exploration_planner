# Global 净空、空间身份与压缩接入（2026-10-30）

本轮实现适用于默认 wavefront 引擎，Global 继续保持 shadow。LocalMapPatch 的未膨胀 body-space 投影仍是唯一几何输入；不改 Local 地面拟合、运动认证、Controller 或 Explorer 的任务选择。这里的 FREE、空间身份和粗路线都不是新的机器人通行证书。

## 净空的含义与来源

`minimum_clearance` 改为完整细路径上各格中心到非自由格面积的保守距离下界，再对路径采样取最小值。EDT 原值是格中心之间的距离；现在减去栅格半对角线 `resolution / sqrt(2)`。例如 0.2 m 栅格的一格宽走道，原值 0.2 m，修正后约 0.0586 m；真实格边界距离为 0.1 m，修正值是保守下界，不能直接当墙到墙宽度。它不是连续扫掠认证，也没有扣除 Go2 身宽或重复膨胀。

局部 EDT 仍只计算一个 tile halo。三种限制分别计算：`occupied` 为 Local 提供的实测占据，`unknown` 为尚无 FREE 证据，`field_limit` 为本次有限距离场的边框。等距来源全部保留；整条边有多个同样最小的样本时合并其来源。`field_limit` 只表示距离下界被计算范围截断，不能称为物理瓶颈；`unknown` 同样不能充当实测墙。

现有 `safe_region_snapshot` JSON 的 `spatial_supports.clearance` 发布定义、投影、栅格误差、halo 范围、`geometry_revision`，并按公开 Node/Edge ID 给出半径和来源。Edge 还发布最小样本的世界整数格坐标、路径支撑 tile 与净空依赖 halo tile。外层 `source_map_revision`、`world_epoch` 与这些字段一起确定证据版本。ROS 消息布局不变；非默认 skeleton 引擎没有这份 wavefront 定义，不应混用它的旧净空数值。

## 空间身份不再要求凸包填满

精确 FREE 行区间仍属于内部几何支撑域，域合并仍要求凸包完全 FREE。这条要求只约束几何计算，不再决定地面颜色。`place_id` 按细图中实际已知 FREE 接口重建连接组，允许一个空间包含多个支撑域、弯折和障碍孔，不会涂掉柱子、墙或 UNKNOWN。

接口只有在路径横截面两侧都由已测占据封闭，且宽度小于两侧邻域宽度参考的 0.6 倍时，才作为空间分隔。宽度参考来自两端及各自一跳邻居的已有净空；横向探测每侧限一个 tile。证据不足不确认物理分隔。`measured_necks` 给出命中样本、两侧墙格、宽度与参考值，便于反查。这个相对几何判据不使用 Go2 身宽，不会删除经过窄口的路线。

因此房间经实测窄门相连可以有不同空间身份；柱子两侧仍有宽阔接口时共享身份。只有 UNKNOWN 围出的收窄不能证明房间边界，后续取得墙体证据后再更新。每次按当前证据重新核对分裂和合并，解决“柱子第一帧就存在有多种颜色，后来才看到却一种颜色”的顺序依赖。旧空间按最大存留重叠继承身份，等重叠时优先旧身份。数值 ID 不要求跨独立运行相同，最终分区应等价。

这里仍不是语义房间识别器。0.6 的收缩阈值、有限横截面和有限距离场均有表达范围；倾斜门户、复杂复合空间需要更多真实输入验收。没有增加历史 place 别名账本，当前 shadow 没有外部任务引用 place_id。

## 曲线、替代路线与接入

公开路网将度为 2 的中间锚点压入 Edge，保留完整路径的长度、最小净空和几何折线。重要狭口可以保留为 Edge 的证据，不必让每个狭口都额外占一个 Node。真正分支、必要覆盖锚点和替代连接保留。若压缩会把真实环压成现有端点对协议无法表示的两条并行边，保留第三个锚点，不覆盖另一条路线。

被压缩的内部域仍发布其精确 FREE 支撑以及 `edge_attachment = [edge_id, polyline_index]`，对应的旧锚点保留为 Edge 折点。消费者先检查域内站位到这个折点的实际几何，再复用已建好的沿边距离索引接入两端。域没有固定 3 m 接入限制；查询不重新建立大范围栅格路线。

单个 2 m tile 的 FREE 分量本身可能非凸，此时一条直线未必能到锚点。Global 复用原有 tile 波前父树，以 `connector_tree` 发布方向编码，每格一个字符，非该分量为 `.`。消费者只沿已算好的父链取出有界路径，并用查询方当前地图逐段重验；不展开 A*，也不生成新的占据图。多格凸域继续只用直线，没有这笔父树数据。引用的 Node 锚点或 Edge 折点必须匹配当前图；边已删除、epoch 过期或路径被新证据否定时不接入。损坏的循环父链有界返回失败，不尝试搜索救援。

## 更新与使用边界

无变化输入继续复用整个 routing view，不做新的结构计算。tile 波前和横截面证据按 dirty 依赖更新；身份核对遍历派生图，重叠计算只对受影响支撑进行，压缩和 JSON 快照目前仍遍历公开图。本轮没有完成设计中的全链路局部发布，也不声称总开销完全独立于历史地图规模。

更正后的 place_id 会通过已有 `spatial_domains` 填色反映到 RViz，颜色不是运动可行性。已在运行的 Python 进程不会自动加载新类，正常结束后重启生效。继续使用原命令并保持 `--global-mode shadow`；无需启用 `route_cost`。短期不要据本轮修改调整 Local 安全门限。

确定性验收位于 `test_spatial_semantics.py`：净空来源与格误差、相同最终地图不同观测顺序、柱子和 L 形空间、实测门口与未知收窄、弯道压缩与远端接入、单 tile 遮挡见证、绕障替代路线及一侧/两侧封闭。消息级回归另验证 JSON 与图快照到达顺序。
